# Playwright Test Project

Цей проект налаштований для запуску тестів у Docker, що забезпечує однакове оточення для всіх розробників.

## Початок роботи

Дотримуйтесь цих кроків, щоб підняти проект на локальній машині:

### 1. Попередні вимоги
Переконайтеся, що на вашому комп'ютері встановлено:
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Node.js](https://nodejs.org/) (бажано версія 18 або новіша)
- [Git](https://git-scm.com/)

### 2. Клонування проекту
```bash
git clone <url-вашого-репозиторію>
cd Final_project
```

### 3. Встановлення локальних залежностей (опціонально)
Це потрібно для підтримки автодоповнення (IntelliSense) у вашій IDE:
```bash
npm install
```

### 4. Налаштування Docker-оточення
Перед першим запуском потрібно побудувати Docker-образ:
```bash
npm run docker:build
```

## Запуск тестів

### Запуск у Docker (рекомендовано)
Це основний спосіб запуску, який гарантує однаковий результат у всіх користувачів:
```bash
npm run docker:test
```

### Перегляд запусків у Docker (UI Mode)
Якщо ви хочете бачити, як проходять тести всередині контейнера через графічний інтерфейс:
1. Запустіть команду:
   ```bash
   npm run docker:ui
   ```
2. Відкрийте браузер на вашій локальній машині за адресою: `http://localhost:8080`

Це відкриє **Playwright UI Mode**, де ви зможете бачити кожен крок тесту, скріншоти та логи в реальному часі.
Якщо виникли проблеми в UI mode такі як, auth файл протух потрібно виконати зупинку контейнера і перебілдити.
```bash
npm run docker:stop
```
```bash
npm run docker:build
```
```bash
npm run docker:ui
```

### Локальний запуск (якщо потрібно)
Якщо ви хочете запустити тести без Docker (наприклад, для дебагу в браузері):
```bash
npx playwright install  # Встановити браузери локально (тільки один раз)
npm test                # Запустити тести
```

## Звіти про тестування

Проект використовує Allure для генерації звітів.

1. **Генерація звіту:**
   ```bash
   npm run allure-generate
   ```
2. **Перегляд звіту:** після виконання команди вище, звіт відкриється автоматично у вашому браузері.

---

## Корисні команди

- `npm run docker:stop` — зупинити та видалити Docker контейнери.
- `npm run docker:build` — перезібрати образ (потрібно після зміни `package.json`).
- `npx playwright test --ui` — відкрити Playwright UI Mode (локально) для зручної розробки тестів.

---

## CI/CD Інтеграція

Проект містить конфігурацію для **GitHub Actions** (`.github/workflows/playwright.yml`). Тести автоматично запускаються в Docker-контейнері при кожному push або pull request у гілку `main`.

Після завершення тестів результати (Allure та HTML-звіти Playwright) зберігаються як артефакти запуску.
